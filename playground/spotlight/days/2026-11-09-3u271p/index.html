UI Spotlight · Day 152 · 9 November 2026

Five effects that measure something instead of waiting

Today's drops all replace a timeline with a quantity. Pixel effects read a seeded hash instead of a sprite sheet; columns read the scrollbar; vines read an alpha mask; pupils read your pointer; a menu reads the angle of your thumb. Each one is rebuilt here in plain HTML, CSS and JavaScript — no libraries, no CDN — with the parameters left exposed so you can feel where the limits are.
