Hold to Confirm

A press-and-hold beats a confirmation dialog: the intent is in the gesture, and letting go cancels it. A conic-gradient ring fills as you hold, then rewinds if you release early.

Each button owns one pointer via setPointerCapture, so a drag off the button still counts as a hold — but pointer-cancel (a scroll starting, a call arriving) aborts cleanly.
