Difference Type

One CSS property carries this whole editorial look: type set in white, blended into a moving backdrop with mix-blend-mode: difference, so the letters invert whatever passes underneath. Move your cursor — the lens inverts everything it crosses, including the type.

Difference blending subtracts the darker colour from the lighter one: a white layer inverts what is beneath it, a black layer changes nothing. That is why the lens is simply a white circle.
