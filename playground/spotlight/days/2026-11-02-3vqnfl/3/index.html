Each place is its own slot. Unchanged places never move — that is the whole trick.

A number that changes place by place

Crossfading one string into another throws the whole value away. Pair the two strings from the right instead and every character becomes a place: the thousands sit still while the hundreds and tens roll, and the currency symbol travels with the place it belongs to.

Place-value roll · default

1,204 → 1,318 rolls the hundreds and the tens. The leading 1 does not move.

Ticking clock · the same rule, once a second

Only the seconds column has anything to do. Minutes move once a minute, hours once an hour.

Words · no places to align, so it pairs from the right

Non-numeric morphs slide and crossfade per slot, and the box width springs to the new string instead of snapping.

Caret matching · type in the field

Right-alignment is wrong while you type — inserting a character would roll everything after it. Matching by caret position keeps the characters you already typed still.
