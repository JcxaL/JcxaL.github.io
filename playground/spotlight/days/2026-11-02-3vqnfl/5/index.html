Components that make their own sound

An interface sound library is usually a folder of WAVs. It does not have to be: a toggle's tick, a stepper's pitched step and an error's minor third are three oscillators and an envelope each — a few hundred bytes of code that never 404s, never waits on a download, and can be re-tuned at runtime.

Toggle · two pitches, one gesture

On rises, off falls. The same component, a fifth apart — which is all it takes to hear the state without reading it.

Stepper · pitch tracks the value

Each step plays a note from a pentatonic run, so the sound tells you how far you have gone and the ends of the range are audible.
