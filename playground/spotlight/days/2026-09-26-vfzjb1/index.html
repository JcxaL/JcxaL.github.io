UI Spotlight · Day 127 · 26 September 2026

Handoffs, Viewboxes, Inter-script Air, Scopes & Springs

Today's five are each a piece of plumbing the browser used to keep to itself. An event hands you the animation it just started. An image carries its own viewBox. The engine inserts the space between Japanese and Latin that a typesetter would. An anchor name stops leaking across a grid of cards. And a spring gets sampled into a curve CSS can run on its own.

DROP 01Animation

Transitions, Handed Over

A transition starts and the event tells you almost nothing — you go fishing in getAnimations() hoping to recognise your own animation. Safari 27 puts the live Animation object on the event itself, so a running transition can be paused, reversed, slowed or scrubbed mid-flight.

DROP 02Layout

Crop Without a Wrapper

Every crop used to cost an element: a box with overflow:hidden and an oversized image shoved around inside it. object-view-box puts a viewBox on the image itself, so panning and zooming happen inside an element that never moves — and the crop animates.

DROP 03Typography

Air Between Scripts

Japanese set next to Latin collides: the two scripts were drawn on different bodies. text-autospace hands the engine the quarter-space that typesetters have inserted by hand for a century — here against a manual hair-space build of the same paragraphs.

Inspired by SymbolFYI — CJK Web Typography

DROP 04Micro-interaction

Anchors That Know Their Card

Anchor names are global, so six cards named --card send all six tooltips to the last one in the DOM. anchor-scope walls each name into its own subtree — and it belongs on the common ancestor, not the anchor. Flip it off and watch the pile-up.

Inspired by Schalk Neethling — anchor positioning, scoping & conditional hiding

DROP 05Component

Press, Squeeze, Morph

Material 3 Expressive made shape the press state: corners collapse under your finger, a selected segment rounds out while its neighbours compress, a FAB morphs into a bar. The curve is a real spring, sampled into a generated linear() easing.
