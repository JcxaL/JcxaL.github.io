Cells That Glide

Grid tracks aren't elements, so nothing can transition between them. Anchor each tile to its own cell and the reflow becomes an inset change — and inset interpolates.

checking…

The grid is plain repeat(auto-fill, …). Each cell carries anchor-name plus anchor-scope so the same name can repeat; each tile is absolutely positioned with position-anchor and sides read from anchor(). Resize this window mid-flight — the tiles redirect from wherever they are, because a transition on a layout value has nothing queued to finish.
