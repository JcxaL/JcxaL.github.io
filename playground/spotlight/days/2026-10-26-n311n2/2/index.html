No Ragged Last Row

The 1px-gap border trick is lovely until the last row runs short and the container shows through. Count the empty slots, fill them, and the grid closes cleanly at any column count.

—

Slots in the final row = ceil(items / cols) * cols − items. Resize the window and the column count changes under you, so the filler count is recomputed from the resolved grid-template-columns rather than hard-coded per breakpoint. One element with grid-column: span n fills the gap without drawing rules between the blanks; separate fillers keep the rhythm of the cells. When row-rule and column-rule gap decorations are everywhere, none of this is needed.
