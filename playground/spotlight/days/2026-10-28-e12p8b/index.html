Nested Groups, Block Centring, Letter Units, Two Hands & Real Inputs

Five demos about things the platform will do for you if you ask properly: a card morph that keeps its own contents inside its rounded box, vertical centring with no wrapper element, units measured from the font instead of guessed in pixels, one button that ships a different interaction per input device, and an upload control that never throws the native input away.

DROP 01animation

Groups That Keep Their Clip

Named elements animate in a flat list, so a morphing card's own thumbnail escapes its corner radius. view-transition-group: contain nests them, and ::view-transition-group-children() is the wrapper you can clip.

Centred Without a Wrapper

align-content works on plain block containers, so vertical centring stops costing an extra element and a new formatting context — and margin collapsing and text-overflow survive the trip.

Units Cut From the Letters

cap, ex, ch and ic are measured from the font in use. Size an icon in 1cap and it matches the capitals at every size, in every family, without a nudged pixel.

Two Hands, Two Buttons

A mouse can preview an action by hovering; a thumb cannot. any-hover and any-pointer let one component ship a magnetic sheen for pointers and press-and-hold commitment for touch.

A Dropzone Around the Real Input

Upload components usually hide the native control behind an opacity-zero trick. ::file-selector-button restyles the browser's own button instead, and drag, paste and preview wrap around a control that still focuses.
