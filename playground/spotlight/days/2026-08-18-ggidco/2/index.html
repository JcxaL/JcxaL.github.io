Editorial Wrap

CSS Shapes lets floated elements bend the text that flows around them into circles, polygons, and even the alpha channel of an image — all without a single line of JavaScript layout code.

01 · shape-outside: circle() / ellipse()

The Basic Shapes

Floating this circle and giving it shape-outside: circle(50%) makes the paragraph text trace the curve instead of the invisible rectangular box the browser would otherwise wrap around. The shape function accepts a radius and position, so a portrait can sit dead-center in a paragraph and still read comfortably on every line.

Switch the shape below and watch every line of this paragraph immediately re-flow around the new silhouette — that recalculation happens on the layout thread, live, with no JavaScript measuring text or repositioning anything.

02 · shape-outside: polygon()

Arbitrary Polygons

A polygon() shape can be anything you can plot as a list of x/y coordinates — a leaf, a star, an organic blob. The trick for keeping the wrap looking intentional is reusing the exact same coordinate list for clip-path (what you see) and shape-outside (what the text respects), so the silhouette and the wrap always agree.

Because both properties read from the same point list here, there's no drift between the visual edge of the shape and the invisible boundary the text is obeying — toggle "Show shape outline" above to confirm it lines up exactly.

03 · shape-outside: url() + shape-image-threshold

Shapes From an Image's Alpha Channel

This image is a five-point star drawn with a radial gradient that fades to full transparency past its edge. With shape-outside: url(...), the browser reads the image's alpha channel directly — everywhere the pixel is more opaque than shape-image-threshold counts as "inside" the shape.

Drag the threshold slider from 0 toward 1: a low threshold treats even the faint transparent glow as solid, pulling text away in a wide berth; a high threshold only respects the fully-opaque star core, letting text creep almost up to its points.
