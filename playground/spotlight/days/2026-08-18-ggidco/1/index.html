Scroll-Linked Icon Morph

Each icon's SVG path shape is tied directly to scroll position via animation-timeline: view() — no JavaScript animation loop, no scroll listeners.

↓ scroll to morph ↓
01 — Discover

Octagon → Star

The path's d value is defined with matching command structure at 0% and 100% of a @keyframes rule, so the browser can interpolate every point smoothly as the element crosses the viewport.

02 — Design

Same technique, own timeline

Every icon on this page gets its own independent view-timeline — scoped automatically to its nearest scrollable ancestor, no named timelines required.

03 — Build

Reverses on scroll-up

Because progress is driven by the element's position, scrolling back up plays the morph backwards automatically — for free.

04 — Ship

Zero JS animation loop

All of this runs on the compositor thread — no requestAnimationFrame, no scroll event listeners, no jank even on a slow device.
