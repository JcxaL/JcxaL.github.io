Cluster motion

A glyph cluster is the smallest movable piece

Not a character, not a code point — a grapheme cluster. Canvas text is segmented into clusters, each one measured and animated on its own. Move the pointer through a line to shove them aside; hover one to see its selection rectangle and the code points hiding inside it.
