Shader Skins, Drawing Sheets, Glyph Clusters, Springs in CSS & Document Links

Five demos about treating the interface as material: live HTML photographed into a GPU texture and distorted, a component dissected into a dimensioned technical sheet, canvas type moved one grapheme cluster at a time, spring motion declared as custom properties instead of animated by hand, and three little documents that exist nowhere but in their own URL.

DROP 01animation

A Shader Over Live HTML

Real markup is captured into a texture, uploaded with texImage2D and re-drawn through a fragment shader that ripples, refracts and dithers it — while the DOM underneath stays selectable. Flip any panel back to the live layer mid-wobble.

Inspired by DavidHDev/canvas-ui · WebGL effects over real HTML

The Component as a Technical Drawing

An Apple-style dimensional sheet: a plan view with hatched padding and dimensioned radii, an exploded translateZ stack of layers you can orbit, and a variable table where the height is a relationship, not a number.

DROP 03typography

Type, by the Cluster

An astronaut emoji is one cluster and four code points. Intl.Segmenter splits canvas text into graphemes, each gets its own box, wave and shove — and Chrome 159's cluster metrics draw the selection rectangle for whichever one you touch.

Inspired by Chrome 159 · enhanced Canvas TextMetrics

DROP 04micro-interaction

Motion, Declared in CSS

Elements ask for --k-tilt, --k-magnetic, --k-repel or --k-drag; one spring loop writes --k-x and friends back as @property values. Every visual decision stays in the stylesheet, and the loop parks itself when nothing moves.

Inspired by amineyarman/Kinesis.js · CSS-property-driven springs

DROP 05component

The Document Inside the Link

A note, a checklist and a sheet whose only storage is the URL fragment: CompressionStream('deflate-raw') plus base64url, re-encoded as you type. Watch the character budget fill, then hand someone the document by handing them the link.

Inspired by aboard-io/tinylittleoffice · the document is the link
