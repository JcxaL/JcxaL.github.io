Sunken initials

A drop cap used to be a float, a magic number and an apology. initial-letter states the intent instead: sink the first letter n lines, optionally raise it by m, and let the browser do the baseline arithmetic. Pair it with text-wrap: pretty and hanging-punctuation and the paragraph starts behaving like set type.

Letterpress · No. 4

The first letter was always the argument

“Openings were set by hand long after the rest of the page was mechanised, because the compositor and the editor rarely agreed about how much authority a paragraph deserved before anyone had read a word of it.

The sink is the whole negotiation. Two lines is a polite cough. Four lines is a proclamation that the rest of the column then has to live beneath, and the measure has to be wide enough to carry it without stranding a single orphaned word.

initial-letter: · Georgia · sink only

Specimen · Raised

Raise it, and the cap climbs out of the block

Second value in initial-letter is the raise: how many of those sunk lines the letter actually sits inside. Set it lower than the sink and the cap lifts above the first line instead of hanging flush with it, which is the cocked-hat look of a mid-century trade paperback.

Because the browser resolves it against the real line box, changing the body size or the leading does not break the alignment the way a hand-tuned float always did.

initial-letter: · raised variant

Specimen · Wrapped

A cap is only as good as the lines beside it

Every line that runs past a sunk capital is short, so the paragraph is exactly where ragged setting looks worst. text-wrap: pretty reworks the last few lines to kill orphans; balance evens a heading out across its lines instead of leaving one word stranded underneath.

Turn on hanging punctuation and the opening quote steps out into the margin, so the column edge reads straight rather than dented — Safari only, and worth it there.
