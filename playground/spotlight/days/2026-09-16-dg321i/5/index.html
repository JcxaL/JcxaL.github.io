The select, unsealed

appearance: base-select pulls the dropdown out of the operating system and into the page — while keeping it a real <select>, with real keyboard handling, real form semantics and real accessibility. Everything below is styled with ::picker(select), ::picker-icon, ::checkmark and <selectedcontent>. No JavaScript opens these.

last change —

Each option carries real markup — a coloured dot here — and <selectedcontent> mirrors it into the button.

Options can preview themselves. A native picker renders text at one weight, because the OS drew it and not you.

Picking one repaints the whole page accent — the control is in the document, so it can be part of it.

Keyboard still works exactly as it always did: type to jump, arrows to move, Enter to commit, Escape to cancel.

This browser has no appearance: base-select, so these are plain native selects — styled as far as the OS allows, fully working, and ready to upgrade the day support lands. That is the whole argument for building on the real element.
