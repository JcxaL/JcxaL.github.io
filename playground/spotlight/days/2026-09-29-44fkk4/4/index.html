Math controls

--dx: 0; --dy: 0;

Direction without branches

Move the pointer over the tiles. JavaScript writes exactly two custom properties per tile — --dx and --dy, raw signed numbers. It never decides which way anything should go. sign() turns the number into −1, 0 or 1 and abs() strips the direction off the magnitude, so a single CSS declaration covers both sides.

Twelve tiles, one declaration

Every tile shares the same transform. The only thing that differs is the number it was given.

Bars that grow both ways

A centred bar normally needs two rules and a conditional. abs() sets the width, sign() sets which side of the centre line it grows from.

Labels that pick a side

The arrow flips to the far side of each chip as the pointer crosses it — left: calc(50% + sign(--dx) * 50%).

sign() is a switch. It returns −1, 0 or 1, so multiplying by it flips a value's direction and multiplying by (1 − abs(sign(x))) isolates the zero case.
abs() keeps layout safe. A negative length that reaches a width or a radius invalidates the declaration; abs() means one variable can feed both a direction and a size.
Fewer style writes. Two numbers per element per frame, no class toggles and no per-direction rules — the branch moved into the stylesheet.
