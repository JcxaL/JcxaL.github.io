Attribute values

data-col="2" data-row="1"

The layout lives in the markup

Every tile below is styled by the same CSS rule. Its column span, row span, order, tint, corner radius and tilt are all read out of HTML attributes with typed attr(name type(<…>), fallback). The panel never touches a style property — it only rewrites attributes, and the layout follows.

Heads up: this browser doesn't support typed attr() yet, so you're seeing the fallback values baked into each declaration — which is exactly what the third argument is for.
Any property, not just content. The old attr() only worked inside content. The typed form works anywhere a value is accepted, including custom properties.
Types matter. type(<integer>), type(<color>), type(<length>), type(<angle>) — an unparseable attribute falls back instead of invalidating the declaration.
No style writes. Changing data-col from 2 to 4 relayouts the grid without a single element.style assignment — the attribute is the state.
