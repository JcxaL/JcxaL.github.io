A model that runs in the stylesheet

No JavaScript on this page — not a line. A keyframe animation counts a seed, a checkbox freezes it the instant you press the button, mod() hashes that seed into noise, and 5 unrolled denoise steps turn the static into structure. Every number below was computed by the CSS engine.

The trick is @property. An untyped custom property substitutes its text, so a chain of var()s referencing var()s explodes; a typed one computes to a value, which turns the cascade into an arithmetic machine. CSS has no loops, so each denoise step gets its own copy of the arithmetic — here clamp(0, .5 + (blur − .5) × k, 1) over a 4-neighbour kernel wrapped on a torus, on a schedule that blurs hard early and sharpens late. The playback only reveals states the engine already settled.
