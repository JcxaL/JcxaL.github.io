The code field that slides, fails and merges

One real <input> hides under the cells, so paste, keyboards and autocomplete="one-time-code" all keep working. A spring carries the focus plate between cells, digits fade up out of a 6px blur, a wrong code dissolves them right to left, and a right one melts the whole row into a single pill. The first code is 204816 — getting it wrong is the better demo.

Plate spring

k = 240, c = 31 is the source's own pairing — just past critical, so the plate arrives without a wobble. Drop damping to 10 and it rings.
