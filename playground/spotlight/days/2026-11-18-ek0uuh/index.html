A stylesheet that computes, a layout that lerps, and type played frame by frame

Today's five are all about machinery you can see: CSS doing arithmetic with no JavaScript at all, container widths turned into one number that every property reads, text animated as a list of frames, a gait that falls out of physics, and a code field that melts into a pill.

Layout That Interpolates

No breakpoints. Each container divides its own width by a length — the tan(atan2()) trick — to get one number, and columns, padding, weight and hue all read it.

Type That Is Played, Not Animated

Six plugins, each a list of text frames with its own hold time. The engine redraws only the rows that changed, honours a per-frame pause, and stops when you look away.
