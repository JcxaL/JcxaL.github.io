RevealTrans

Three panels, one startViewTransition — every effect is CSS on the ::view-transition-new() pseudo-element.

Transitions from 1997

Internet Explorer 5.5 shipped RevealTrans: twenty-four page transitions you declared in a <meta> tag and the browser ran for you. Every one of them is a mask or a clip — which is exactly what the View Transition API hands you today.

All three panels swap inside a single document.startViewTransition(); each one runs a different effect because each has its own view-transition-name.

This browser has no startViewTransition() — the panels still swap, they just cut instead of transitioning.
