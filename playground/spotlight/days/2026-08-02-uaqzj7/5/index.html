Auto-Height Accordions with calc-size()

Height transitions used to mean measuring scrollHeight in JS because CSS refused to animate to/from auto. interpolate-size: allow-keywords plus the calc-size() function fix that natively — every panel below animates to its true content height with a plain transition: height, no ResizeObserver, no measuring, no layout thrash.

Your browser doesn't support calc-size() / interpolate-size yet — panels below still open and close, just with an instant height jump instead of a smooth animate-to-auto.

It lets a CSS value depend on an intrinsic sizing keyword — auto, min-content, max-content — and still be animatable, which those keywords normally aren't.

For the common case — expand to fit content, collapse to zero — yes. You still reach for JS for measuring against a max-height cap or syncing multiple panels' scroll position.

Unsupported browsers just see the height jump instantly instead of animating — the content still opens and closes correctly, so it degrades safely rather than breaking.
