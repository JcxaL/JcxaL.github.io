CSS Anchor-Positioned Tooltips

Every tooltip library exists to solve one problem: "follow that other element, and flip to the other side if you'd overflow the viewport." anchor-name tags a reference element, position-anchor tethers a second element to it, and anchor() reads that anchor's edges directly in CSS — position-try-fallbacks handles the flip. No JS position math, no ResizeObserver, no scroll listener.

Your browser doesn't support CSS anchor positioning yet — tooltips below fall back to a fixed corner instead of tracking their anchor.
