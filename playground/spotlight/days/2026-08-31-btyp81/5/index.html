The :open Selector

One selector — :open — now matches <details>, <dialog> and any popover element whenever it's showing. Every glow, chevron rotation and reveal below is written once per element type, driven purely by that shared pseudo-class.

Accordion · <details>
Does :open replace the [open] attribute selector?⌄

Not exactly — [open] still only matches elements with the attribute. :open is broader: it also matches a <select> or <input> whose picker is showing, and any popover, all with one rule.

Does this need any JavaScript?⌄

None. The chevron rotation, border glow and content reveal on this accordion are 100% CSS — details:open plus a CSS-grid 0fr → 1fr track trick for the height animation.
