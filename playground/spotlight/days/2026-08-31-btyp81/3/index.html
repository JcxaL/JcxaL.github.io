Container Tone

Each card below reads a single custom property — --tone — set on its own container. Flipping the button changes that one variable; every visual change you see is resolved by @container style(--tone: …) rules, not by JavaScript touching the DOM style.

Serif, heavy, confident — the default mood before any style query fires.

Tone: Neon

Glow different.

Same markup, same h2 — the style query swapped in glow, tracking and a display color.

Tone: Mono

RUN THE NUMBERS

A technical register: monospace, uppercase, tight tracking — one property flip away.

speak softly
