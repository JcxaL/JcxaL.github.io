A control the form believes in

Three components below. None of them contains an <input>. All three appear in new FormData(form), answer to form.reset(), block submission when invalid and match :user-invalid — because static formAssociated = true plus attachInternals() makes a custom element a real form control instead of a decoration sitting next to a hidden field.

Rating

Contributes one value via setFormValue(). Its validity is published with setValidity({ valueMissing: true }, message, anchor), so the browser's own "please fill in" flow points at it.

Accent

A plain single-value control with a default, so you can watch form.reset() reach inside a shadow root via formResetCallback().

Budget

One element, two named entries. setFormValue() accepts a whole FormData, which is the part that finally retires the pair-of-hidden-inputs pattern.
