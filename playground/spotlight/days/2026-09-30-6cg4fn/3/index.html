Same size, different size

Every one of these paragraphs is set at the identical font-size. They do not look it, because what the eye reads as "size" is the x-height, and every family picks its own share of the em. font-size-adjust hands the browser a target ratio and lets it re-solve the font size until it hits it — which is exactly what a fallback needs while the webfont is still in flight.

1 · Five families, one font-size

Switch Mode to match and Georgia's own measured ratio becomes the house style for all five. Turn on Guides to watch the x-height rules snap into a single row. The declared size never moves; the used size, printed on each card, does.

2 · Which metric do you want matched?

Two families per card, same declared size, each normalised to a ratio measured off Georgia. The keyword decides which landmark is held constant — lowercase height, capital height, or the advance width of a digit. Matching one does not match the others.
