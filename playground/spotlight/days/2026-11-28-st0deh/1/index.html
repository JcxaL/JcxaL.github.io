The random is in the stylesheet

Every dot, bar and piece of confetti below gets its position, hue, size and timing from CSS random() — no loop writes an inline style. The roll is per element by default; hand it a --dashed-ident cache key and every element sharing that key resolves to the same value instead (last section). Values resolve once at style time, which is why a burst looks identical on its second click — it is random, not animated.

1 · Sparkle field — 90 elements, zero coordinates written by hand

2 · Confetti buttons — each piece flies on its own angle

Each chip sits in a wrapper whose own rotate: random(0turn, 1turn) is its direction, so one shared keyframe that only does translateX throws every chip down a different line — a real polar scatter, with no sprite sheet and no per-piece JavaScript.

3 · Equaliser — 44 bars, four random axes each

4 · The gotcha — one roll, or one roll each

random(h, s)
random(--tone, h, s)

Same function, same range, same twelve elements. The top row rolls once per element — that is the default. The bottom row passes a --dashed-ident cache key, so every element sharing that key resolves to the identical value: useful when a hue and a shadow must agree, surprising when you wanted a scatter.
