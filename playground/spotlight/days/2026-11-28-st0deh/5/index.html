The native select, finally styleable

For twenty years a dropdown that didn't look like 1998 meant rebuilding <select> out of divs — and reimplementing typeahead, focus trapping and the mobile sheet by hand. appearance: base-select hands the rendering over while the element stays a real form control: these three pickers are a grid of cards, a colour swatch matrix and a styled list. All are one <select> with <option>s. Keyboard, form value and typeahead still work.

1 · Grid of cards

The trigger renders <selectedcontent>, so the closed state can show the same rich markup as the option — it must sit inside a <button>.

2 · Swatch matrix

Each option carries its own --sw, and ::checkmark is moved on top of the chosen swatch instead of taking a column.

3 · Styled list + stagger

The picker is a popover anchored to its select automatically; the entry animation needs @starting-style plus transition-behavior: allow-discrete so display can animate.

Technique per Chrome's custom select picker layouts guide · UI Spotlight Day 171 · Drop #5
