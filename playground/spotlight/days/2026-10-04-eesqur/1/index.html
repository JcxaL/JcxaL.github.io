Animating What Isn't There

Pseudo-elements have no DOM node, so for years the only way to move them was to swap a class and let CSS run the show. element.animate() takes a pseudoElement option — which means ::before, ::after and ::backdrop get the full Web Animations API: one shared timeline you can pause, reverse and scrub.
