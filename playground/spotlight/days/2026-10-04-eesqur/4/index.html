Let the Fling Keep Its Place

A drag that ends in a Web Animations fling has one classic bug: the moment the animation finishes, the element snaps back to wherever CSS says it lives. commitStyles() writes the animation's computed end state onto the element's own style attribute, so you can cancel the animation and the element simply stays put — you keep the landing spot without leaving a forwards-filling animation outranking every later style change.
