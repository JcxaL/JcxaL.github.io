Swarm

Nothing here was rendered by a human.

A crew of cursor agents flies in, drags out each frame, sweeps a scan line down it and types the copy in character by character — then leaves.

Frame

Dragged, not faded

An agent grabs one corner and pulls the border out to size before any content exists.

Scan

Swept into being

A scan line runs the height of taller boxes, leaving the surface behind it.

Type

Typed, not revealed

An I-beam walks the text and types it in. The DOM keeps the real string the whole time.
