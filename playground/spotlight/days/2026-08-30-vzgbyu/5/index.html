Combobox Controls

Popover Combobox

A searchable combobox with zero manually-managed floating divs — the option list is a native popover element with automatic light-dismiss and top-layer stacking, positioned against its trigger. Full ARIA combobox/listbox semantics and keyboard navigation throughout.

01 · Country picker

Type to filter, ↓/↑ to navigate, Enter to select, Esc to dismiss.

02 · Command palette style

Trigger button opens a categorized, filterable action list.

03 · Inline tag adder

Combobox that adds chosen items to a tag list below instead of filling an input.
