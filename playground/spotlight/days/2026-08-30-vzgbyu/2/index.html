Balanced Rows

CSS is about to ship flex-wrap: balance — it fills the same number of lines as a normal wrap, but redistributes items so every line is close to the same width, instead of leaving one ragged short line at the end. Toggle each panel below to feel the difference. (Native support is still landing in browsers, so this demo runs the same min-max partitioning algorithm in JS as a working preview.)
