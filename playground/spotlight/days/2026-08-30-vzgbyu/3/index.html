Axis Controls

Weight Choreography

True variable fonts expose continuous axes like wght, slnt, and custom ones such as Recursive's playful CASL. System UI fonts don't ship those axes, so here the same feel is faked with two crossfaded weight layers, letter-by-letter — the classic trick for variable-font choreography without loading a variable font file.

01 · Proximity swell

Move your cursor across the headline — nearby letters swell toward the maximum weight.

02 · Weight + slant + casual-axis rows

Hover a row — its label crossfades to bold and leans, like a zero-JS menu riffing on Recursive's wght/slnt/CASL axes.

03 · Ambient breathing

Idle animation — weight gently pulses across the line even without interaction.
