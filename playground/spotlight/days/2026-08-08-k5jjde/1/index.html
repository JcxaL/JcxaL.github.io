Drop 01 · Animation

Now Playing

Three real, silently-synthesized audio tracks — no network request, no CDN. Every glyph, shimmer, and pulse below is driven by the actual playback state of an <audio> element: playing, buffering, seeking, muted. Zero animation-timing JS — just state ● native :playing supported.

How it works

New Selectors Level 4 media pseudo-classes — :playing, :paused, :seeking, :buffering, :muted, :volume-locked — match <audio>/<video> by live playback state, so keyframes can react with zero timeupdate listeners. Support is still rolling out, so this demo mirrors the same state via real media events (play/waiting/seeking/volumechange) into data-state attributes — the CSS shown is written exactly as the native selectors would be.
