How it works

@layer a, b, c; declares priority — later names win, no matter where each layer's rule block appears in the file. A layer's priority is fixed forever the moment it's named, so this demo mints a freshly namespaced set of layer names on every reorder to stay genuinely live. Any unlayered rule automatically outranks every layered one, which is why the yellow override always wins when enabled.
