Try selecting this paragraph — the highlight color follows the same tint. And this focusable link (tab to it) picks up a matching focus ring.

Chrome 150 shipped the AccentColor / AccentColorText system colors, but for fingerprinting-privacy reasons the real OS value is only exposed inside an installed web app on your primary profile — a plain browser tab like this page can request it but will typically get a generic fallback, not your literal desktop accent. This demo is honest about that: the swatch requests the real keyword via @supports (accent-color: AccentColor) and applies it live, so what you see is exactly what your browser is willing to hand over right now.
