Real forced-colors mode can't be toggled from a webpage — it's an OS accessibility setting (Windows High Contrast, or a browser's own forced-colors flag). The banner above uses matchMedia('(forced-colors: active)') to report your actual device state live; the "Simulate" button mirrors the same CSS rules manually so the technique is visible to everyone reading this. In forced-colors mode, most authored colors, box-shadows and backgrounds are stripped by the browser — system-color keywords keep working because they resolve to whatever palette the user actually chose.
