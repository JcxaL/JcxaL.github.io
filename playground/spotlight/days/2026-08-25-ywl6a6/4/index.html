Coalesced Ink

Draw fast with a mouse, finger, or stylus. Toggle between naive pointermove sampling and getCoalescedEvents() — the difference shows up as jagged corners versus a perfectly smooth line, and in the raw point counter below.

Move events: 0 Points drawn: 0 Points per event: 0.0

A browser coalesces several real pointer samples into one pointermove event to save work — great for scrolling, costly for ink. event.getCoalescedEvents() hands back every sample the OS actually captured since the last frame, so a fast stroke gets drawn through all of its true positions instead of just the last one. Try a quick flick in each mode: naive mode visibly cuts corners.
