One declaration, four hosts

The same contract is declared once and handed to four renderers. Leave a colour, a radius or a type size unspecified and each host answers with its own: iOS inset lists and a large title, macOS traffic lights and 13px chrome, a browser toolbar, a framework-painted GTK headerbar. Specify it as the author and every host obeys — precedence runs author → platform → default, which is exactly how these CSS layers are stacked.

Precedence

With the author layer off, nothing in the contract names a colour or a size, so every host paints with its real controls. Flip it on and the authored values win in all four at once.
