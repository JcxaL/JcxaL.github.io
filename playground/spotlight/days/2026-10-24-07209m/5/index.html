Details that open smoothly

The disclosure widget has been in HTML for a decade and has been impossible to animate for almost as long. ::details-content gives the hidden half a box to transition, allow-discrete keeps it painted on the way out, and interpolate-size lets the height land on auto.

Instance 1 — exclusive accordion, height to auto

1Why could nobody animate this before?

The content of a closed <details> was not a box you could address. There was nothing to put a transition on, so every library in the world re-implemented the widget with a wrapper div and a measured pixel height.

The pseudo-element changes that: the slot holding everything except the summary is now styleable, and it is a real box with a real size.

2What is allow-discrete doing here?

Closing the element flips content-visibility from visible to hidden, and that property is discrete — it would snap, taking the content out of the page before the height finished shrinking.

Adding allow-discrete to that part of the transition keeps the old value until the end of the run, so the collapse is visible all the way down.

3And interpolate-size?

Transitions need two lengths, and auto is not one. Opting a document into interpolate-size: allow-keywords lets the browser interpolate to intrinsic sizes, so the panel can animate to exactly the height of its own content.

Where it is missing, the @supports not block in this page pins the open height instead, and the widget still works — it just opens instantly.

4Is it still accessible?

Yes — it is the native element. Keyboard activation, the expanded state in the accessibility tree and find-in-page all come for free, which is the part the hand-rolled wrapper versions usually got wrong.

Instance 2 — the same pseudo-element, animating inline-size

Panel A

Nothing says the transition has to run vertically. Give ::details-content an inline size and the disclosure opens sideways, like a drawer in a dock.

Panel B

Each panel is an independent <details>, so several can sit open at once.
