The space between scripts

Set a Latin word inside a Japanese sentence and it needs a sliver of air on each side — about an eighth of an em. Typesetters have inserted it by hand for a century; text-autospace asks the browser to do it.

The simulated row inserts a literal 0.125em span at every boundary, so the effect is visible even where the property has not shipped. Browsers that do support it shape the gap into the glyph advance instead, which keeps the text selectable as one run.

Unicode’s East Asian Spacing report splits characters into wide, narrow, other and conditional classes. Spacing is added at wide↔narrow boundaries only — so digits and letters get air, while punctuation and symbols are left alone.

At display sizes the missing gap is the difference between a headline that looks typeset and one that looks pasted together. The property is inherited, so one declaration on :root covers a whole document — and no-autospace opts a single run back out.
