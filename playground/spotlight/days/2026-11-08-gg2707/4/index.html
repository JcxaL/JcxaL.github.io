Point cloud

Agent state orbs

One point cloud, four readings. An assistant that is resting, taking input, working and answering should not need four different widgets — the same few hundred particles carry all of it through radius, band brightness and ejection. Tap an orb to drive it by hand.

How it reads. Rest breathes on a slow sine. Listen couples the radius to an input envelope so the sphere inflates with the voice. Think contracts the cloud and runs a bright band around its latitudes — motion that is clearly internal, not responsive. Speak ejects particles on syllable onsets and lets them fall back, which is why it looks like output rather than input.
