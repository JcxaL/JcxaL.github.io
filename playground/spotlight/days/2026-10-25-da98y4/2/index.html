A hinge is a layout constraint, not a bug

Safari 27.1 on the iPhone Duo exposes the Device Posture and Viewport Segments APIs, so a page can finally ask where the fold is and keep content out of it. These three apps are driven by the same two numbers those APIs hand you — segment height and hinge thickness.

The frames above are a simulation so you can see the behaviour on any screen. On real hardware the numbers come from env() instead — the panel reports what your device actually says.

/* real foldable, no simulation */
@media (vertical-viewport-segments: 2) {
  .screen {
    display: grid;
    grid-template-rows:
      env(viewport-segment-bottom 0 0)                                  /* top segment */
      calc(env(viewport-segment-top 0 1) - env(viewport-segment-bottom 0 0)) /* hinge */
      1fr;                                                      /* bottom segment */
  }
}
/* and in JS */
navigator.devicePosture.type        // "folded" | "continuous"
window.viewport.segments            // [DOMRect, DOMRect]
