Type as Architecture

Letters sampled into a grid, then extruded into towers that rise on a staggered timeline and keep orbiting. Every skyline is just a word — no meshes, no 3D library, one 2D canvas per scene and a painter's-algorithm sort.

Tap any skyline to rebuild it. The build-up delay is a function of grid position, so the word assembles left-to-right instead of popping in — that stagger is what makes an extrusion read as construction.

Inspired by Serhii Polyvanyi — “Turning Names Into Digital Architecture with Three.js” (Codrops) · UI Spotlight Day 119 · Drop #1 · reimplemented in vanilla Canvas 2D
