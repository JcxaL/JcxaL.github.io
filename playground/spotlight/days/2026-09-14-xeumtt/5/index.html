Findable When Folded

Every accordion you have ever shipped hides its answers from ⌘F. Collapsed content set with hidden="until-found" stays searchable: the browser finds the text, fires beforematch, unhides the panel and scrolls to it. Firefox 148 and Safari 26.2 shipped it in 2026, so it is finally a pattern you can rely on rather than a Chromium trick.

The whole component

<button aria-expanded="false" aria-controls="a3">Why Verlet?</button>
<div id="a3" hidden="until-found"> … answer … </div>

panel.addEventListener('beforematch', () => {
  trigger.setAttribute('aria-expanded', 'true');   // the browser is about to
});                                                // reveal it — stay in sync

toggle(){                       // our own click path removes the attribute
  panel.hidden = open ? 'until-found' : false;
}

beforematch fires before the reveal paints, which is the only moment you get to fix up state that CSS cannot see. Without it the arrow still points sideways while the answer is plainly open.
