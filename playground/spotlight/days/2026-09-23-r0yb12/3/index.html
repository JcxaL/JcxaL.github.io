Underlines With Padding

text-decoration-inset trims or extends a decoration at each end — the thing we have faked with pseudo-elements since forever. Positive values pull the line in, negative values push it past the glyphs, and it animates.

checking support…

01 · Trimmed to the glyphs

The default underline overshoots the first and last character. Drag the panel sliders — or watch this one sit flush.

A rule that knows where the word stops and ends there.

02 · Outset into a bracket

Negative insets extend the rule beyond the text run — an editorial underline with shoulders, no extra markup.

Set −0.28em on both ends and it reads like a caption rule.

03 · Hover grows the inset back to zero

Transitioning the inset wipes the rule in from the start, instead of scaling a pseudo-element.

Hover this link, then this longer one, then this strike-through.

Keyboard: Tab works too — the wipe is bound to :focus as well as :hover.
