The player, as elements

The skinned media player is the original component library: a window that drags and resizes itself, an LCD that is also a scrub control, a bank of sliders that mean something. Rebuilt here as four custom elements in the light DOM — <sk-window>, <sk-lcd>, <sk-slider>, <sk-toggle> — with no framework underneath.

Skin

Drag any titlebar. Drag the hatched corner to resize — the window streams --w and --h as it goes. Drag across the LCD to scrub. The EQ bank really shapes the spectrum above it.

Every one of these is a plain HTMLElement with a connectedCallback that wraps its own children and a few pointer listeners — attributes in, input events out. The window writes --x/--y/--w on itself while you drag, so the layout stays in CSS and the element only ever moves numbers.
