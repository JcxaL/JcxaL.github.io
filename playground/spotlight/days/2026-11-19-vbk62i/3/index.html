One font per script

A font stack picks a different face for every character it cannot draw — and then leaves you with the result: digits too small, kana too large, punctuation sitting at the wrong height. A composite font keeps the per-character fallback but tunes each class: its own face, its own size, its own baseline. Top line in each card is the plain stack. Bottom line is the same string, balanced.

Per-class tuning




size-adjust on a @font-face that owns a
unicode-range is the whole trick for size: the browser already routes each character to a face,
and the descriptor rescales just that face. Baseline is the part CSS cannot do alone — a real composite font
bakes the shift into the outlines, so here the toggle stands in for it with a per-run
vertical-align.
