Outlines on springs

Not a cross-fade between two icons — one contour, re-sampled so both shapes have the same points, with a closed-form spring carrying every point from one to the other. The spring is solved analytically, so there is no integration loop and no drift: ask for the value at t and get it.

Spring

Each shape is a radius function sampled at the same 128 angles, so point i of the circle and point i of the star are the same point in two poses — morphing is then just lerp per point, with one spring value steering all of them. The same spring writes transform on the press, which is why the outline and the body feel like one object.
