Views that turn to grains

An exit animation that doesn't move the view — it ends it. The view is sampled once into a grid of grains, and from then on only the grains exist: a few hundred coloured quads, each stepped by one function per frame. Tap any card to blow it apart; tap again to run the same curve backwards and reassemble it.

Grain engine

Each grain carries only its source rectangle and colour. A preset is a pure step function f(grain, t, origin) → {x, y, scale, rot, alpha}, so out and in are the same function read in opposite directions, and the cascade is nothing but a per-grain delay derived from its distance to the point you touched.

Inspired by rs-4/dissolve — a Skia + Reanimated engine that captures any React Native view and animates it as one atlas of grains · UI Spotlight Day 162 · Drop #1
Reimplemented here on a 2D canvas: the views are drawn, not captured.
