Melt

Melt Type

Layered SVG filters (feGaussianBlur → feColorMatrix → feOffset) fuse each letter's blur back into a sharp, gooey edge, then a keyframe loop stretches every glyph downward like warm wax.

Each letter drips on its own staggered timer — hover to slow the whole line down.
