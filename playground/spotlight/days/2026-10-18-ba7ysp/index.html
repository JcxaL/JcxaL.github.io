Five features that each delete a line of JavaScript

Today's drops all replace something you were tracking by hand: the direction an animation is running, which element a two-axis scroller settled on, how wide a column actually is, which link the user clicked, and whether a slot got any content. Each demo says up front whether your browser ships the real thing or is running the fallback.
