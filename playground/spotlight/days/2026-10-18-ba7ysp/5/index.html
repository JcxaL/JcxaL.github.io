Slots That Know They're Empty

An optional slot with nothing in it still occupies its padding, its border and its gap. :empty is no help — it describes the slot's own children, not the content assigned to it. :has-slotted matches a slot that actually received light-DOM content, so a component can collapse its own optional regions from inside its shadow stylesheet.

/* inside the shadow root */
slot[name="footer"]:not(:has-slotted) { display: none }
slot[name="media"]:has-slotted        { border-bottom: 1px solid var(--line) }

Native support is Firefox 136 and up. Where it is missing this page sets a data-shim attribute on the host and listens for slotchange to mark each slot [data-filled] — the same collapse, but now the component carries a script to describe its own markup.
