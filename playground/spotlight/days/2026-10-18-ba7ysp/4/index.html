The Link That Stays Lit

Which thumbnail did the user click? Until now only JavaScript knew — you listened for navigate, read NavigateEvent.sourceElement and tagged the element yourself. Chrome 156 ships :navigation-source, which matches that element in CSS and keeps matching it for the whole navigation, so the press state and the view-transition name can both be declarations.

checking support…
Pick a card. The one you clicked keeps its ring and its glow until the navigation finishes.

The grid is a set of real links to #card-n, so each click is a genuine same-document navigation. :navigation-source is what paints the ring where it is supported; everywhere else a navigate listener adds a .nav-source class and removes it when the navigation settles — the same behaviour, four more lines of script.
