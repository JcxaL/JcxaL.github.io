Type That Counts Its Own Pixels

Dividing two values of the same type is legal CSS now, and the result is a plain number: calc(100cqi / 1px) is how many pixels wide the container is. Feed that number to font-weight, letter-spacing or line-height and the type responds to its own box — no clamp stack, no breakpoints, no ResizeObserver.

checking support…
font-weight from width

Grotesque gets heavier as its column gets wider.

font-weight: clamp(200, calc((var(--n) - 180) * 1.6), 900);
letter-spacing + word-spacing from width

Narrow columns open the tracking; wide ones tighten it back down.

letter-spacing: calc((640 - var(--n)) * 0.0085px);
line-height + hue from width

Leading loosens as the measure narrows, which is the opposite of what a fixed line-height does to a cramped column. The hue is driven by the same number, so you can see it move continuously rather than in breakpoint steps.

Drag the resize handle in the bottom-right corner of any card, or use the slider.

line-height: calc(1.2 + (760 - var(--n)) * 0.0011); color: hsl(calc(var(--n) * 0.46) 68% 76%);

The trick is that the divisor carries the meaning. calc(100cqi / 1px) counts pixels; calc(100cqi / 1em) counts ems; calc(100cqi / 320px) gives a 0–1 progress ratio you can multiply into an angle or a colour channel.
