UI Spotlight · Field Notes

Set the type loose.

Oversized, viewport-scaled type is the loudest trend of 2026 — a single word stretched edge to edge, negative space doing the work stock photography used to do. But scale alone is not craft.

The quiet upgrade sitting underneath it is hanging-punctuation: quotation marks and commas that fall at the start or end of a line are pushed outside the measure, so the text edge — not the glyph — defines the column.

Flip the switch in the panel to feel the difference. It's subtle. Editors have cared about it in print for a century; browsers finally do too.

"The eye reads the edge of the column, not the edge of the ink — hanging punctuation just makes CSS agree with print."
— Typesetting, since Gutenberg

Three quote styles are staged below, each testing a different glyph against the hang: English double quotes, a French guillemet, and a lone apostrophe on a line-ending word.

«A second voice, set with guillemets, drifting past the margin on both ends.»
