Renderer

The file that styles itself

One plain-text file: a CSS block between two --- rules, then ordinary CSV. Any CSV you already have is a valid one — add the block and the data arrives dressed. The element parses it, drops the rows into a shadow root so nothing leaks, reads --cssv-key back out of the computed style to decide which column becomes each row's data-key, and lets the file's own rules target tr[data-key="Total"].

invoice.cssv edit me

rendered <cssv-table> · shadow root

Change --cssv-key to another column name — or to col(2) — and every row's data-key changes with it, because the renderer asks the stylesheet, not the markup.
