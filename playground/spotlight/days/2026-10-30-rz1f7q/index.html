Draft Stacks, Pages With No Classes, Composite Type, Ray-Built Faces & Self-Styling Data

Five demos about showing the working: a finished film playing in lockstep with the rough blockouts it grew from, three copies of one class-free document under a zero-specificity stylesheet, four fonts worn as a single family and tuned slice by slice, faces computed from 128 radii and a sphere behind each pupil, and a plain-text data file that arrives already dressed.

DROP 01animation

The Draft Underneath

One clock drives five renderers. The polished film runs on top; the four rough blockouts sit under it, and the one whose section is on screen follows frame for frame while the rest loop their own beat. Scrub, slow it down, or fade the draft back over the finish.

A Page With No Classes

The same class-free markup in three shadow roots: bare, under a classless sheet whose every rule hides in :where(), and under the same sheet with your tokens. Add one plain h2 rule and watch it beat the framework with no !important.

DROP 03typography

One Typeface, Four Fonts

A composite family built live: the same font-family name declared four times, split by unicode-range and tuned per slice with size-adjust. Drag the figures slider and a single unchanged text node resizes only its numbers.

DROP 04micro-interaction

A Face Built From Rays

No sprites: each outline is 128 radii lerped toward the next shape by a spring, and each pupil is a point on a sphere turned by Rodrigues' rotation, so it foreshortens near the edge instead of sliding. Only changed attributes are written — the counter proves it, then falls to zero.

Inspired by ArvinYin1/grokbot-animation-anatomy · procedural SVG rigs

DROP 05component

The File That Styles Itself

CSS between two --- rules, then ordinary CSV. The element parses it into a shadow root, reads --cssv-key back out of the computed style to pick each row's data-key, and the file's own tr[data-key="Total"] rule does the rest.

Inspired by rhpaiva/cssv · data and stylesheet in one plain file
