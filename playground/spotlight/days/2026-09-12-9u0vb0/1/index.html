One shape, ten moods

The whole avatar is a single closed path. Each state is nothing but a set of radial harmonic amplitudes, and every transition is those numbers travelling on a spring — no keyframes, no morph library, no second path to interpolate against.

Spring

The mechanism. Sample 120 angles around a circle; the radius at each angle is R · (1 + Σ aₖ·cos(kθ + φₖ)) for k = 2…5. A state is just the vector [a₂,a₃,a₄,a₅, scale, spin, squash]. Springs pull the live vector toward the target vector every frame, the phases drift on their own clock so the shape never sits still, and the sampled points are stitched into one smooth path through their midpoints.
