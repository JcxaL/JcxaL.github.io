Five patterns that move the work into the declaration

Today's five share a streak: each pushes the behaviour out of a script and into something the browser already runs — a custom property, a keyframe, a scroll container, a file that carries its own stylesheet. Open each one, pull the controls apart, and watch how little code is actually left.

A typewriter with no script

The sheet is the scroller

No drag handlers and no animation loop. The sheet sits in a scroll container whose snap targets are the detents, so flinging it is plain scrolling and the platform's own snapping picks where it lands. The backdrop fades on a scroll() timeline.
