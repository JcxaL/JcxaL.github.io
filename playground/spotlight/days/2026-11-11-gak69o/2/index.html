The stylesheet lives in the data

One plain-text file. A CSS block between --- fences, then ordinary CSV underneath. Delete the fenced block and you still have a perfectly valid spreadsheet export — keep it, and the browser renders a styled table. Edit either half below.

quarter.cssvsource
rendered<cssv-table>

How it holds together. A custom element splits the file on its --- fences, drops the CSS half into a <style> inside its own shadow root — which is what stops those rules leaking into the page — and builds a table from the CSV half. Before rendering it reads --cssv-key off the table to learn which column names each row, then stamps that value onto data-key so a rule like tr[data-key="Total"] can find it. Cells get data-col for column-wise rules, and numeric cells get a --n custom property, which is how the heat-map example paints itself with nothing but CSS.
