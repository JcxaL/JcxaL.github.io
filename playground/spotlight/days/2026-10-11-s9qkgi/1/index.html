Every control calls effect.updateTiming() or sets playbackRate on the three animations that are already running. Nothing is cancelled, re-created, or re-read from CSS.

Retime it while it runs

A CSS animation is a declaration you replace. A WAAPI animation is an object you can renegotiate with: effect.updateTiming() changes duration, iteration count, direction, easing and iteration offset of a running animation, and playbackRate scrubs it — including backwards — without ever restarting it.
