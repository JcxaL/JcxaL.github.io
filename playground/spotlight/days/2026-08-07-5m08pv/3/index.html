Drop 03 · Typography

Cursor-Driven Text Dissolves

Three ways to make a block of type behave like matter: an ASCII lens that re-renders words as density, a cipher that decrypts under a flickering wavefront, and glyph rain that lights the copy as it falls. Move the pointer across any panel — leave it alone and a ghost cursor takes over.

01

ASCII Lens

Real type is rendered once, sampled for ink density per cell, then redrawn as ramp glyphs inside the lens.
02

Decrypt Reveal

Every cell starts as cipher; proximity drives a per-character resolve, and the boundary flickers as it lands.
03

Glyph Rain

Falling streams illuminate the letters they pass; the column your cursor cuts through surges ahead.

Dissolve parameters

All three panels share one character grid and one rAF loop; only the cells near the pointer are redrawn as glyphs.

Inspired by DavidHDev/canvas-ui (Asciify · Decrypt Reveal · Glyph Rain) — rebuilt on a plain 2D character grid instead of the html-in-canvas API
