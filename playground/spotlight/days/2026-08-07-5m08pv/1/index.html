Thinking Orbs

Agent loaders that say what the machine is doing, not just that it is busy. Every orb is plain 2D canvas arcs — dots placed on rotating orbits, no WebGL, no filters, one shared clock for every instance on the page.

Working

Particles on three tilted orbits, depth-sorted so the far side dims and shrinks as it swings behind.

Searching — the meridian sweep tells you it is reading, not stalling.
Weaving — three strands plaiting: merging results from several tools.
At 16 px the same renderer still reads — dot count and radius scale with the box.

Orb parameters

Every canvas shares one rAF loop and pauses when the tab is hidden or the orb scrolls offscreen.
