Zero-JS Enter & Exit

Cards animate in on insert and animate out on removal — @starting-style plus transition-behavior: allow-discrete do the whole thing. JS only adds/removes a class.

The mechanism
Entry: a new .item is inserted with the base rule already in place, but the browser first paints it using the @starting-style override — then transitions from there to normal on the very next frame.

Exit: JS adds .removing. Because display is listed in transition-property with allow-discrete, the element keeps rendering at its old display value for the full transition duration, then flips to none at the end — so opacity/transform get to finish before the element vanishes from layout.
