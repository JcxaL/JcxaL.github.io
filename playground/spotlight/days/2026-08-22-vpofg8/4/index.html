Feel the Interface

Real device haptics via navigator.vibrate() — each pattern is an array of pulse/pause durations. Since vibration itself is invisible, the bars below light up in sync so you can "see" the pattern too.

checking haptics support…

Tap · nudge

A single short pulse — confirms a light action, like a toggle flip.

Success · double

Two quick pulses — the classic "done" confirmation.

Error · buzz

One longer, harsher pulse — something needs attention.

Hold · escalating

Pulses that ramp up — press and hold to feel it build.
