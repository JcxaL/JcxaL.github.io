Randomness, Declared

CSS can finally roll its own dice. random(min, max) hands every element its own value — no inline styles, no loop in JavaScript writing custom properties. Give it a dashed ident to cache one roll across several declarations, add element-shared to make every match agree, or pass a third argument to quantise the result.

Parameters

checking…

01 · Confetti rain

Horizontal position, hue, opacity, fall duration and spin all come from separate rolls.

02 · Equaliser

Each bar caches one roll for its resting height and another for its cycle length.

03 · Scatter field

Two rolls place the dot, a third sizes it, a fourth tints and drifts it.

The declaration

.chip { left: random(--pos, 0%, 100%); animation-delay: calc(random(0, 1) * -6s); background: hsl(random(185, 335) 85% 62%); } /* one ident = one cached roll reused by every declaration on that element; add element-shared to make the whole selector agree on a value */
