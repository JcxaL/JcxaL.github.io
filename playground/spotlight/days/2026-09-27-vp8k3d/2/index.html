Where it does not work 0 skipped

The same 400 rows in a real <table>, with the same declaration on every <tr>. Not one of them is skipped: containment does not apply to internal table elements, because a table cannot size its columns without looking at every cell. If you need a skippable table, the rows have to stop being table rows — which is what the grid above is.

What the toggle changes

With skipping off, every element above is laid out, styled and painted on load. With it on, the browser defers all of that until the element approaches the viewport, then fires contentvisibilityautostatechange so you can start or stop your own work in step with it — pausing a video, tearing down a chart, unsubscribing a socket.
