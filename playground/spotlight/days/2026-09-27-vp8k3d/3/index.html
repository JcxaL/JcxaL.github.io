Markers Without a Name

A counter style used once never needed a name. symbols() builds an anonymous one right where you use it — in list-style-type, in counter(), in the shorthand — and the five counting systems each read the same symbol list differently.

One list, five systems

Same three-to-ten symbols, five different readings: cyclic repeats them, numeric treats them as digits in base-n, alphabetic counts like spreadsheet columns, fixed runs out and falls back to numbers, and symbolic repeats each one more times per cycle.

  3. Pick the hotspot
  4. Ship it
