Window States

Every responsive layout you have ever written asked the same question: how wide am I? A maximized window and a hand-dragged window of the same width are very different rooms, though. display-state asks the window manager instead — so the rail can expand when the app is maximized and the whole chrome can step aside in fullscreen.
