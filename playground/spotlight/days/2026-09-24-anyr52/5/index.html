States From Inside

A component knows things the page does not: that it is uploading, that the last attempt failed, that the user already voted. ElementInternals.states publishes those facts as real CSS state, and :state(busy) styles them from outside the shadow boundary — no class juggling, no data- bookkeeping, no reaching into the element.
