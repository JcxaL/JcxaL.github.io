Concurrent View Transitions

Chrome 147 shipped element.startViewTransition() — a transition scoped to one element instead of the whole document. Flip a few cards fast in Scoped mode and each morphs independently. Switch to Global mode and the classic document.startViewTransition() makes every click block on the last one.

Inspired by Chrome for Developers — "Element-scoped view transitions" (Chrome 147) · UI Spotlight Day 79 · Drop #1
