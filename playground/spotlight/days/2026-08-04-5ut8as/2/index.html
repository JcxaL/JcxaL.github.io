Field Notes — Issue 79

Between Ink and Interface

A running folio in the margin, a drop cap that anchors the eye, pull-quotes that break the grid — three spreads that borrow a print magazine's typographic conventions and rebuild them with grid-template-areas, CSS counters, and container queries.

Structure — 01

Grid Areas as Layout Grammar

Fig. 01 — asymmetric column split

Every named area in this spread — eyebrow, media, text, quote — reflows independently when the container narrows, because the layout is described once and reinterpreted per breakpoint via a container query scoped to the spread itself, not the viewport.

"The grid doesn't just hold content — it argues for a reading order."
Structure — 02

Full-Bleed Break, Then Two Columns

Fig. 02 — full-bleed pause between chapters

A full-bleed image acts as a paragraph break at the scale of the whole page — the kind of pacing a printed spread gets for free and a scrolling page has to construct deliberately.

Beneath it, columns: 2 switches the reading rhythm from wide to narrow, letting the eye rest in shorter line lengths exactly where the density of information increases.

Each paragraph declares break-inside: avoid so the column-fill algorithm never orphans a single line at the top of the second column.

The folio counter keeps incrementing invisibly in the background — every .spread is one unit, regardless of how many CSS columns it renders internally.

Structure — 03

Sidebar Footnotes, Live Folio

The number in the top-right corner of this page is not a static label — an IntersectionObserver watches which .spread currently owns the most viewport area and writes its counter-increment position into that badge, the same way a printed magazine's running head tells you which article you're inside without needing to find the page number yourself.

Scroll back up slowly and watch the badge count down as each earlier spread reclaims the majority of the screen.

MarginaliaFolio numbering here uses counter(folio, decimal-leading-zero) so single digits render as 01, 02, 03 — a small print-shop convention carried over verbatim.
