BroadcastChannel

One component, every window

Three independent documents, one state. new BroadcastChannel(name) is a same-origin bus any tab, window, iframe or worker can join — no server, no storage events, structured clone for free. These panes elect a leader, answer late joiners with the current state, and show who is still listening.

Change the accent, the counter or a checkbox in any pane — the others follow within a frame. Open the real fourth window from the panel and it joins the same channel.

Inspired by Steve Kinney — Broadcast Channel for cross-tab UI · UI Spotlight Day 131 · Drop #5
