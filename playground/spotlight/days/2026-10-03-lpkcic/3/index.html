line breaking

Breaks that know the phrase

Japanese has no spaces, so browsers have always wrapped it anywhere a character ends. word-break: auto-phrase hands the line breaker a small on-device model (BudouX) that finds phrase boundaries first — the same sentence, broken where a reader would pause. It only runs on text marked lang="ja", so the language attribute is doing real typographic work here.
