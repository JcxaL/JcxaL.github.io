Scroll Shapeshift

Every panel below is animated purely by CSS scroll timelines — no IntersectionObserver, no scroll event listeners. Corners morph from round to spiky superellipses as each panel enters view.

↓ scroll to trigger ↓
01 · view()

Entry, tied to viewport

Each panel's animation-timeline is set to view(), which scrubs progress based on how far the element has travelled through the scrollport — reverse-scroll reverses it automatically.

02 · superellipse()

Corners as math, not radius

The new corner-shape property accepts a superellipse(n) curve. Because it's numeric, it interpolates smoothly between squircle, notch and star silhouettes.

03 · scroll(root)

A rail with zero JS

The progress rail at the top uses animation-timeline: scroll(root) — its scaleX keyframe just runs from 0 to 1 across the whole document's scroll range.

04 · animation-range

Scoped entry windows

animation-range: entry 0% cover 35% confines the morph to the first 35% of the element crossing into view, so it settles before you've finished scrolling past it.
