Elastic Path Type

Every letter is placed on the same bezier with offset-path: shape() and distributed by sibling-index(). Hover bends the curve’s control points and an elastic linear() easing snaps the word along it.

Icon Morph Spring

Nine stroke icons, any pair. Both get resampled to 64 arc-length points, a 2D Procrustes fit finds the rotation and scale that align them, and a 240 Hz damped spring carries the residual — interruptions keep their velocity.
