One toast that morphs in place

Not a stack. The next call reaches into the toast already on screen and changes it — icon, text, height, progress — and the box springs to its new size instead of cutting. Height, lift and scale all run on the same solver, so interrupting a move keeps its momentum rather than restarting from zero.
