Spec

One JSON spec per chart: type, data, encoding, options. The renderer tweens from wherever the marks already are, so new data never restarts the chart.

A chart is a spec, not a drawing.

Three charts, no chart library, no canvas: every mark is an SVG element placed from a small JSON spec. They draw in when they scroll into view, tween from their current positions when the data changes, answer the keyboard, and carry a data table for screen readers.
