One declaration, both axes

Safari Technology Preview 254 added size, min-size and max-size: shorthands that set the inline and block dimensions together. One value squares the box; two values read inline-then-block, so they follow writing mode instead of fighting it.

FIXED

Two values: inline then block.

size: var(--w) var(--h);
SQUARE

One value sizes both axes.

size: var(--h);
CLAMPED

Four longhands become two declarations — and this card grows to fill the row between them.

size: auto; min-size: var(--minw) 110px; max-size: var(--maxw) 260px;

Why it matters: min-width/min-height/max-width/max-height are four physical properties that quietly break the moment a component is dropped into vertical writing mode. min-size and max-size are logical, so the same rule survives the rotation — and a constraint pair that used to need four lines now needs one.
