One file, six themes

An external SVG has always been a sealed box: you could scale it, you could not recolour it. CSS Linked Parameters open a door in the side. The SVG declares its inputs with env(), the page fills them in with link-parameters: param(…), and the same asset comes back wearing whatever palette the element asked for.

THE SAME SIX, INLINED what we ship today

To theme an SVG today you stop linking it and start inlining it — six copies of the markup in the document, no shared cache entry, and the icon system grows a build step.

/* inside the SVG — it declares what it will accept */ <circle fill="env(--accent, #8ea2bb)" …/> /* on the page — the element fills them in */ .poster-3 { link-parameters: param(--back, hsl(330 36% 15%)), param(--accent, hsl(10 70% 58%)), param(--ink, hsl(340 52% 88%)); }

Note the direction of control. The SVG decides which knobs exist and what happens when nobody turns them — the env() fallback is why the file still renders correctly on its own, in an editor, or in a browser that has never heard of the feature. The page cannot reach in and restyle arbitrary internals; it can only answer the questions the asset chose to ask. That is what makes this safe for an icon set you do not own.
