A Height That Ends on a Tile

A repeating background doesn't care where your box ends, so the last row gets sliced. background-repeat: round fixes it by stretching the art. This doesn't: calc-size(auto, round(up, size, var(--tile-h))) reads the box's own auto height and snaps it up to a whole number of tiles — the pattern stays exactly the size it was drawn.

The ratio under each box is height ÷ tile. The padding is rounded to the tile in every mode, so the height rule is the only thing changing: on auto the ratio lands wherever the text leaves it, and on round up or down it is always whole — down never taller than auto, up never shorter.
