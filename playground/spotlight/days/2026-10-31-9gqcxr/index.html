Anchored Curves, Heights That End on a Tile, 1997 WordArt, Buttons You Hold & Icons Chosen by CSS

Five demos about letting the stylesheet do the arithmetic: a connector drawn by four anchor-positioned boxes of which only one ever has a size, a section that rounds its own auto height up to a whole number of background tiles, WordArt rebuilt out of a textPath and four filter primitives, five microinteractions stripped back to a transition-delay and a captured pointer, and an icon set that lives entirely in custom properties.

DROP 01animation

The Curve Between Them

Three pairs of draggable dots joined by a line nothing draws. Four quadrant boxes sit anchored between each pair; only the one matching the diagonal has a size, and border-shape paints an S-curve across it. Bring a pair close and the control point collapses — same command list, so it interpolates.

DROP 02layout

A Height That Ends on a Tile

A repeating background doesn't know where your box stops, so the last row gets sliced. calc-size(auto, round(up, size, var(--tile-h))) reads the box's own auto height and snaps it to a whole number of tiles. Drag the word count and watch three panels hold still, then jump.

Make Text Like It's 1997

WordArt, and not a canvas in sight. The arch is a <textPath> riding a quadratic, the 3-D is the same string stamped a dozen times down the light angle, the chrome is a <linearGradient>, and the bevel is four filter primitives. Type and all three slabs follow.

Five Ways to Answer a Click

A microinteraction kit taken apart: a delete button that makes you mean it, a label you drag instead of type, letters that leave one at a time on a transition-delay, a border that lights where the pointer is, and a checkbox with real overshoot. Three of each.

Icons the Stylesheet Chooses

The icon is a design token, not an <svg>. A masked pseudo-element takes currentColor, a @container style() query stops the rule firing on elements that never asked, and inherits: false is the line that keeps a nested <strong> from growing its own.
