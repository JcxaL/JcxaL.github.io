Outlines that don't eat the letters

-webkit-text-stroke draws half its width inward, so a heavy outline quietly swallows the letterforms — counters close up, thin joins disappear. One line fixes it: paint-order: stroke fill puts the stroke behind the fill, so the outline only ever grows outward. Chromium picked the property up for HTML text, so it now works everywhere without duplicating the text into a pseudo-element.
