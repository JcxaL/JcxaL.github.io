Metric overrides

shift: —

Fallbacks that
don't jump

The font swap is the last big layout shift most sites still ship. The fallback has different metrics from the real face, so the moment it swaps every line below moves. The fix is not to hide the text — it is to reshape the fallback so it already occupies the right box, using size-adjust and the three *-override descriptors on a @font-face that points at a local font.

1 · The same swap, twice

Hit Swap the font (or the button below) and watch the red marker move while the green one stays put. Both panels swap to the identical target face.
