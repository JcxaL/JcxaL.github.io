A list only has to exist where you can see it. A virtual scroller keeps one tall spacer so the scrollbar tells the truth, renders just the visible slice, and then recycles those few elements as you move — no creation, no destruction, no garbage. Scroll the list below to the bottom and the element count in the panel never budges.

1 · The list

One million rows. Drag the scrollbar hard, or use the jump box — the row count on the right is the number of <div>s that actually exist.

people —
Why recycle rather than re-create? Creating and dropping nodes on every frame is what makes naive virtualisation stutter — the cost is not the scroll, it is the allocation and the style recalculation on a changing node set. Reuse the same elements and the browser only ever does a text and transform update.
