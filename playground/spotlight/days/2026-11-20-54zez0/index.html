Baked timelines, lanes, shrinkwrap, fields & a toast that morphs

Five patterns pulled from this month's releases: an arcade round solved up front and written out as pure CSS keyframes, WebKit's brand-new grid-lanes layout mode, text measured before it hits the DOM so a bubble can shrink to its longest line, pointer proximity exposed as a CSS custom property, and a toast stack that refuses to stack.

The Game Is Baked Into the Keyframes

A deterministic solver plays the whole invasion once, then writes every hit, march step and laser out as a percentage stop. Playback runs on the animation engine alone — zero JS frames.

Lanes, Not Columns

Declare lanes with grid-template-columns and the browser drops each item wherever it lands closest to the top. Rows instead of columns lays bricks sideways; fit-tolerance decides when to jump.

Type That Knows Its Own Width

CSS can't shrink a wrapped box to its longest line, so every chat bubble carries dead space. Measure in canvas first — no DOM, no reflow — and the widest line becomes the width.

Proximity Is a CSS Variable

Hover is binary; distance isn't. One listener publishes --nf and a unit vector toward the pointer, and magnetic, tilt and glow are all just calc() on those three numbers.
