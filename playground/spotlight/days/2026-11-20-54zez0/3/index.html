Type that knows its own width

CSS can shrink a box to its content on one line. It cannot shrink a wrapped box to its longest line — so every chat bubble carries dead space on the right. Measure the text first, in canvas, with no DOM involved: prepare() caches each segment's width once, layout() walks the line ranges, and the widest line becomes the box width.
