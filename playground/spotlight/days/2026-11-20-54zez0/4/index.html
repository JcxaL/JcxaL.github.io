Proximity is a CSS variable

Hover is binary: in or out. A near-field turns the pointer's distance into a continuous number and hands it to CSS as --nf (0 far → 1 touching) plus --nf-x / --nf-y, a unit vector toward the pointer. One passive pointermove listener and one shared rAF loop feed every element; the effects are plain CSS calc() on those three values.

Magnetic — pull toward the pointer, spring back

Tilt — lean in as the pointer approaches

RadiusThe field starts at the element's nearest edge, not its centre.
EasingRaw distance is eased, so the last few pixels do the most work.
SpringsA fixed 120 Hz substep keeps the feel identical on any display.

Glow — a light that tracks the pointer

Everything above reads the same three custom properties. No per-effect listeners.
