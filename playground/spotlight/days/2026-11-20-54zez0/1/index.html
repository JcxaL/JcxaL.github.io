The game is baked into the keyframes

A deterministic solver runs the whole invasion once, then writes every event out as a percentage stop in a CSS @keyframes timeline. Playback is the browser's animation engine alone — no requestAnimationFrame, no JavaScript, no timers. The same trick lets an SVG play a full arcade round inside a GitHub README.
