Lanes, not columns

Grid Lanes is a new layout mode: you declare the lanes with ordinary grid-template-columns, and the browser drops each item into whichever lane leaves it closest to the top. Columns give you a waterfall; declare grid-template-rows instead and the same engine lays bricks sideways. fit-tolerance decides how big a height difference has to be before the algorithm bothers to jump lanes.
