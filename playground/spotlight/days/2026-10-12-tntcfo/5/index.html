A custom checkbox that is still a checkbox

Styling a checkbox usually means hiding the real one and hoping the replacement keeps its manners. Andy Bell's pattern keeps the native <input> in place, stretched invisibly over the box it controls, so focus, keyboard, form submission and the accessibility tree are untouched — the only thing added is an SVG tick revealed by :checked. Everything scales from one font-size.

1 · a real fieldset

Tab into it. The focus ring belongs to the actual input, sized and rounded to match the visible box.

—

2 · labels that wrap, boxes that stay put

align-items: baseline plus an ex-based nudge keeps the box on the first line's baseline however far the label wraps. Narrow the column and watch it hold.

3 · radios, indeterminate, and scale

The same box with border-radius: 50% is a radio; a second icon covers the mixed state. Every dimension is in em, so one slider resizes all of it.

—

This is deliberately a stopgap. ::checkmark with appearance: base would let you style the browser's own indicator instead of rebuilding it — but it isn't implemented anywhere yet, so the honest version is the one that leaves the native control doing its job.
