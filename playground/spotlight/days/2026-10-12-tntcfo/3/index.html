Type that is measured to its box

Fitting a headline to the space it has always meant measuring in JavaScript or stacking clamp() on container units and hoping. Chrome 150 added text-fit, which asks the layout engine to pick the font size that fills the box instead. Everything below declares the intent once; where the property is missing, the same intent is resolved by a binary search so you can see the behaviour either way.

1 · a poster headline

One line, resized to the width it is given. Drag the poster width and the type tracks it continuously.

The browser is choosing a size per element from the space actually available, so nothing is truncated and nothing needs a breakpoint. text-fit takes consistent to size a block's lines together, or per-line to let each line fill the measure on its own.
