Variation axes

The text is the chart

Every glyph in this face is a bar, and the character you type is its height — a is short, z is tall. So a waveform is a string: selectable, editable, styleable, and three variation axes away from a different look.

01 · Live signal

A string rewritten 30 times a second. Nothing is drawn — the text content changes.

02 · Type your own data

Letters a–z map to heights. Type, paste or pick a phrase — the bars follow the characters.

03 · Same string, three alignments

One value row set bottom, centre and top by the YELA axis alone.
