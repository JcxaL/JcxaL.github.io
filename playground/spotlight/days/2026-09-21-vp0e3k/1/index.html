TRANSITION

DROP 01 · ANIMATION

One declaration,
every element named

A view transition can only morph elements it can identify, and view-transition-name has to be unique — which historically meant minting an id per row in JavaScript. match-element lets the browser derive identity from the element itself, so a whole list becomes animatable with one rule.

01 · REORDER & FILTER A DECK

Every tile carries view-transition-name: match-element and view-transition-class: tile. The class is what the ::view-transition-group(.tile) selector tunes — no per-element CSS anywhere. Filtering passes a type, so the same elements animate differently depending on why they moved.

02 · THE SAME DATA, A SECOND VIEW

This rail renders the same records. Because identity comes from the element rather than a shared string, both views can animate in the same transition without name collisions.

03 · BOTH AT ONCE

One startViewTransition() that mutates the deck and the rail. Every participant gets its own group, animating concurrently.
