MULTICOL

DROP 02 · LAYOUT

Multicol grew
a second axis

For twenty years multi-column layout could only make a page taller. column-wrap and column-height let columns wrap into rows, row-rule decorates the new gaps, and ::column makes each generated column box a scroll-snap target — which is how you get a magazine.

A · WRAPPED COLUMNS

Same prose, but capped at column-height: once a column fills, the next one starts, and when the row runs out of width the whole thing wraps down. column-rule draws the vertical gaps and row-rule the horizontal ones — gap decorations that used to need pseudo-element hacks.

B · ::column AS A SNAP TARGET

The columns here aren't elements — there's no wrapper per column to hook onto. ::column addresses the boxes the fragmenter generated, and it accepts exactly the properties that don't disturb layout: scroll-snap-align, scroll-snap-stop, scroll-margin. Add ::column::scroll-marker and the page gets a pager for free.

C · THE GAPS, DECORATED

Rules follow the gaps, not the items, so they survive reflow. Change the rule style in the panel and both axes update together.
