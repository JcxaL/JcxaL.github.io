DROP 03 · TYPOGRAPHY

Type that measures
itself

Fluid type with clamp() scales with the container and ignores the string, so a short headline sits small and a long one overflows. text-fit scales with the text: grow it until it touches the edges, shrink it until it stops overflowing — length included in the maths.

A · GROW vs CLAMP, SAME BOX

Drag container width and retype the headline. The clamp() line only knows the box; the text-fit: grow line knows the box and the glyphs it has to place in it.

font-size: clamp(18px, 6cqi, 64px)—
Type that fills the box
text-fit: grow—
Type that fills the box

B · GROW, SHRINK, PER-LINE

Three modes on the same three strings. grow scales up from the base size, shrink only ever scales down to stop an overflow, and per-line fits each line independently — the ransom-note look, done properly.

C · WITH A CEILING

Unbounded growth looks absurd on a wide screen, so max-font-size caps the scale factor. Slide the cap and watch the headline stop climbing.
