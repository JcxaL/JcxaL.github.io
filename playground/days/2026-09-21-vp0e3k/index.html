Shader Forge

    
A fragment shader runs once per pixel. You write main() and set
       gl_FragColor. Everything recompiles as you type.

    
    
      
  • Uniforms — u_res u_time u_mouse u_frame
    • 
      
  • Helpers — rot() hash21() vnoise() fbm() pal() PI TAU
    • 
      
  • Sliders — add //@param name min max default
    • 
      
  • Colors — add //@color name #ff0066 → a vec3
    • 
      
  • PNG — downloads the exact current frame
    • 
      
  • REC — records the live canvas to a .webm file
    • 
      
  • Link — packs the whole shader into the URL hash
    • 
      
  • Keys — Space play/pause · Ctrl/⌘+S save · Ctrl/⌘+Enter recompile
